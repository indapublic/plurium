Click any tab. Each one is signed in to a different account, and Plurium switches the profile for you.

Chrome gives every profile its own window. Plurium gives them one.

With profiles in Chrome you keep a window per account and hunt for the right one with ⌘`. Plurium joins those windows into one, with a single tab strip you can order however you work.

Separate profiles, shared strip

Only the window is shared. Everything else about a profile stays its own.

Fully isolated profiles

Each profile keeps its own cookies, logins, extensions and history. Two accounts on the same site sit side by side without signing each other out.

Any order you like

Drag tabs anywhere in the strip, across profiles. The order survives restarts. The profile mark can be a line on top, a corner, a side bar or nothing.

Chrome's shortcuts, across profiles

⌘1…⌘9, ⌃Tab and ⌘⌥→ follow the shared strip. ⌘⇧T reopens the last closed tab of any profile, right where it was. ⌃1…⌃9 jump to a profile.

Move a tab to another profile

Opened a link in the wrong account? Right-click the tab, choose Plurium → Move to, and it reopens in the other profile at the same place.

Vertical tabs, pinned tabs, groups

All three work with the shared strip. Pinned tabs of every profile come first; a group belongs to one profile and keeps its tabs together.

Incognito and fullscreen too

Incognito windows join the strip as “Work (Incognito)”. Fullscreen covers the whole window, with the same strip on top.

Updates itself

New versions download in the background through Homebrew. An Update button appears in the strip, and the relaunch brings back all your tabs.

Open source

Plurium is a set of patches on top of a stable Chromium release, under the BSD license. They're on GitHub, with a guide to build it yourself.

Install

Plurium keeps its own profiles and never touches the data of Chrome or Chromium installed next to it.

Homebrew Recommended

Installed this way, Plurium installs its own updates with one click.

Terminal
brew tap indapublic/plurium https://github.com/indapublic/plurium
brew trust --cask indapublic/plurium/plurium
brew install --cask indapublic/plurium/plurium

Uninstall with brew uninstall --cask plurium. Add --zap to also delete the profiles.

Disk image

Drag Plurium to Applications. It tells you when a new version is out, and you download it again yourself.

Before you switch

Plurium is a one-person build of Chromium, not Google Chrome. Here's what that means.

  • No Chrome SyncGoogle doesn't let third-party Chromium builds use Sync or browser sign-in. Signing in to websites works as usual. To bring bookmarks and passwords over, export them from Chrome and import them in each profile.
  • No Netflix or Spotify WebThere's no Widevine, so DRM-protected video and music don't play. Ordinary video does.
  • Security fixes can trail ChromeEvery Chromium security release needs a full rebuild of Plurium, which takes hours. Fixes reach Plurium after they reach Chrome, sometimes by days.
  • Not every tab feature yetNo tab hover previews, tab search or split view, and you can't drag a tab out into its own window. Some built-in texts still say “Chromium”.

Questions

Is this a Chrome extension?

No. Chrome draws each profile's tabs in that profile's own window, and an extension can't change that. Plurium is a browser: Chromium with patches to its window and tab strip.

Will it read or change my Chrome profiles?

No. Plurium keeps its profiles in ~/Library/Application Support/Plurium and doesn't touch Chrome's or Chromium's data. You start with fresh profiles and bring over what you need.

Do Chrome extensions work?

Plurium is Chromium, so extensions work the same way, installed per profile.

Why isn't it in the Mac App Store?

Apps in the Mac App Store must run in Apple's App Sandbox, and Chromium's multi-process design doesn't run inside it. Brave, Vivaldi and Chrome itself aren't there either.

Intel Mac? Windows?

Not now. Plurium is built only for Apple Silicon, and it relies on macOS window tabs, so there's no Windows version.

How much does it cost?

Nothing. Plurium is free and open source, under the same BSD license as Chromium.
